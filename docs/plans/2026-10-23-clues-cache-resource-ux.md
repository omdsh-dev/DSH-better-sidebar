## 可观察结果

- 帮助收进线索 Tab 页头下方：选资料、插入、发送三个图标短步骤，另有一句线索包提示。没有全屏、遮罩、Modal、inert 或全局 focus trap。首次按浏览器记录；页头 `?` 随时开关。
- 来源列表、搜索、置顶、包成员和添加页携带同一资料信息，详情统一工具栏、摘要、查看／编辑、正文和稳定底栏。所有格式只在有改动时显示一个底栏 Save；Ctrl/Cmd+Enter 走同一路径，正文不重复保存按钮。

## 公共契约和数据来源

`ClueResourceInfo` 是独立的只读展示快照，挂在 candidate/read/edit/save 结果上，也可随 subtitle 经 ensure 保存到 Clue。它覆盖 state、number/repository、author/assignees/followers、labels、createdAt/updatedAt/completedAt、start/due、branches、counts、path/sizeBytes。宿主负责有界校验、时间转 ISO、URL 校验及安全复制；只读 info 不进入远端写请求。

ensure 同值不写盘、不增加修订，已有行改变展示快照才返回 updated:true。保存后只用来源确认的 info 更新已存在资料；直接保存未入库候选不创建线索。展示快照写盘失败不会把已确认的远端保存伪装成可重试失败。GitHub 后读失败时不拿保存前快照充当保存后的 info。文件 mtime 明确以毫秒处理。

来源 filters 声明 scopeKey、适用 list/search、默认选项及 value；无 value 删除键，false 保留。主浏览器和包添加页共用组件，GitHub 仓库未确定时不提供可能写成孤立 state 的筛选；仓库字符串也会保留。

## 缓存与边界

成功读保留在插件激活期内存中，上限128项及约16 MiB。显式刷新或有关写入才使其失效，错误不缓存；超大单项服务本次请求但不保留。在飞读最后消费者离开后最多保留5秒，新关键词取消旧搜索，无新周期轮询。来源页保留分页、已消费游标、草稿和滚动。

请求按 workspace、session、范围、游标和 offset 隔离；session 可能影响来源审批／路由，不能全局忽略。保存通过有界 clueId↔locator 别名索引同时失效两种身份和所有 session 的该资源读，并失效资料库／绑定修订；绑定面板保存后重新取得修订。其他正文缓存和包目录保持有效。

普通账号状态重查不清空业务数据；实际账号／授权／能力改变、明确连接动作及可执行路径改变会保守清除业务读，防止跨账号复用。历史“包含内容”发送使用 readFresh，浏览缓存不能伪装成发送时读取；当前默认仍只发送稳定引用。本机 Agent API 按请求读取，不走浏览器缓存。浏览器刷新或插件重新激活会清空内存正文，不宣称跨重启缓存或自动同步外部修改。
