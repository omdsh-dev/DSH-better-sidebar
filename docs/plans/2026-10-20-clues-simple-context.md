# 线索作为会话上下文：简化交互与自动默认

用户反馈优先于此前手动选择范围的设计。沿用当前主题分支与未提交的 UI 改动，不改 DSH 源码与 3384 实例。

## 产品行为

- 线索是可直接插入会话的外部上下文；线索包是随读取更新的线索集合。
- 上方小型线索包列表，下方较大的线索浏览区。折叠横栏及列表占满可用宽度，折叠即时完成。
- 常用动作只有预览、插入会话、组合成包。绑定、提及独立开关、批量及技术信息收进可选高级区域。
- 加入包只选择目标；已有包点击即添加，新包输入名称后创建，不再重复审核选择。
- 所有来源都有合理默认：本地使用当前工作区根；GitHub 使用当前工作区 git remote 对应仓库（明确覆盖优先）；飞书文档默认云盘，关键词搜索使用账号可访问文档；任务使用当前账号。
- 默认值只用于当前读取，不自动持久化为用户覆盖。没有可推断仓库时解释原因并提供修改范围入口。
- 缺依赖或授权的来源在浏览位置直接给出原因及安装/授权入口。沿用现有受管安装、进度、取消和授权能力，技术细节按需展开。
- 查看可编辑线索时并列预览和编辑，共享草稿；窄窗自适应。只读来源只显示预览。保持保存冲突与未保存保护。
- 公共浮窗 API 默认填满内容区域，滚动由内容和明确 scroll 模式控制，不要求消费者逐个补 fill。内容区去掉统一无谓外边距。
