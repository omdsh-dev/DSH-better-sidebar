# 代码专注模式与拖拽收起设计（2026-08-25）

> 状态：已实现（分支 `feat/custom-development`）。

## 目标

- 右侧工作台左缘拖到窗口最右侧并松手时，执行与「折叠侧边栏」按钮相同的收起动作。
- 新增「代码专注模式」按钮：代码工作台临时接管会话主区域，再次点击恢复进入前的侧栏宽度。
- 保留 DSH 自带的左侧工作区导航；底部面板打开时，专注代码区位于其上方，底部面板横向占满原会话区与代码区。

## 布局与状态

- 普通侧栏宽度仍由每会话的 `SidebarState.width` 持久化。
- 专注模式是组件级临时状态，不写入 `SidebarState.width`。进入时使用 `window.innerWidth - centerColumn.left`，以覆盖层方式接管会话与详情区域；根布局仍保留普通侧栏的宽度推挤，避免 DSH 自带的左侧工作区导航因根节点变窄而触发响应式折叠。退出时直接恢复持久化宽度。
- 会话切换到侧栏关闭的会话、进入窄屏布局或主动折叠侧栏时，自动退出专注模式。
- 专注模式下隐藏水平缩放条与双向角拖柄，避免临时展示宽度覆盖用户保存的普通宽度；底部面板高度仍可调整。

## 拖拽收起

- 面板显示宽度在拖拽中继续遵守 280px 最小值，避免内容被压成不可用的细条。
- 指针进入距窗口右边缘 96px 的收起区时，缩放条显示强调反馈；仅在该区域松手才折叠，普通窄宽调整不会误触。
- 收起不改写保存宽度，重新展开恢复拖拽前宽度。
- 缩放条提供键盘行为：方向键左/右以 40px 调整，按住 Shift 时以 80px 调整；位于最小宽度时继续向右即折叠。

## 验收

- 专注模式进入/退出不改变 `SidebarState.width`。
- 专注模式覆盖会话主区域但不覆盖左侧工作区导航；底部面板打开时仍完整可用。
- 快速拖动且只在 `pointerup` 带最终坐标时也能正确折叠。
- 拖拽到收起区再取消时沿用既有中断提交语义，不留下卡住的拖拽状态。
- 中英文按钮文案、`aria-pressed`、可聚焦分隔条和键盘调整均可用。
