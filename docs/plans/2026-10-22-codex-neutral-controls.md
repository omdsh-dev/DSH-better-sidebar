# Codex 式中性控件修正

日期：2026-10-22。状态：已通过定向测试及真实宿主验证，已部署到 3080。

## 反馈与范围

用户指出上一轮的反色不自然，并要求参考 Codex UI。这里采用克制的中性操作层级，不声称逐像素复刻。官方介绍页通过搜索找到，但本轮页面抓取受 DNS 限制，未把搜索摘要当作配色规格。

修复源头是把按钮文字前景同时用于开关旋钮的角色混用。未新增框架、依赖或运行状态；不改布局、交互及五秒请求保护。

- 主按钮：填充取 `label-primary`，文字取 `bg-base`；浅色深底白字，深色浅底深字。hover 向画布混合。
- `#3388BB`：只承担焦点、选择 tint、开关轨道与状态提示，不再大面积用于主按钮填充。
- 开关：独立 `--ds-sidebar-switch-on-thumb`，自绘与宿主原生 Switch 都使用浅色开态旋钮。
- 危险确认：继续使用错误态填充，并单独设置可读前景，不被中性按钮配方牵连。
