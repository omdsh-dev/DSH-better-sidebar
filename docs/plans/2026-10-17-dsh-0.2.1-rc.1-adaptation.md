## 3. 正式版进入 latest 的明确风险

v0.28.0 **即将接管插件 npm `latest`**，而 DSH 自身的 npm `latest` 此时仍指向 **0.2.0-rc.2**。用户已明确接受这一标签分离：不能把“宿主和插件都装 latest”当作兼容安装方法。

- 新用户须先显式升级宿主到 `0.2.1-rc.1`，再安装插件 v0.28.0。
- 旧 rc.2 宿主必须固定 `dsh-better-sidebar@0.26.1`；旧 alpha.5 固定 `dsh-better-sidebar@0.28.0-alpha.0`。
- 不为保留旧宿主而放宽本版 peer 下限。
- 发布沿用现有 workflow：无预发布后缀的插件版本进入 `latest`，不修改 workflow，也不把本次插件正式版标成 alpha。

正式版安装命令（发布完成后）：

```sh
dsh plugin --profile web add dsh-better-sidebar@0.28.0
```
