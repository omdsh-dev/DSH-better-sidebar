# 设置、浮窗与线索工作台的统一设计

日期：2026-10-22。状态：已实现、通过验收并部署到 3080；3384 未被本次操作修改或重启。

## 用户目标

全面解决页面边距、间距、宽度不一致；设置、浮窗和线索收集 Tab 使用同一套现代、清晰、直观的设计语言。默认强调色为 `#3388BB`。主要提交动作遵循阅读顺序，位于底部或右下角。快速切换不重复轰击数据源。质量优先，复用已有结构，删除重复样式与不必要的防御分支。

## 设计决定

- 保留宿主 UI primitives、原生菜单和现有 CSS Modules，不引入新的组件框架或全站 CSS reset。
- 中性画布与文字继续使用宿主角色令牌；插件统一定义可覆盖的强调色令牌，默认 `#3388BB`，聚焦环、选中 tint、开关轨道与状态提示使用该色。主要按钮遵循 Codex 式中性黑／白层级，避免蓝底暗字的突兀反差；按钮文字反之取当前画布层，开关旋钮使用独立的浅色令牌。原生资源图标保留识别色。
- 采用工具型密度：正文/资源标题 13/20，辅助文字 12/18，元信息 11/16；4px 间距节奏，组件间距 8/12/16；控件 32px，图标控件 28px，触控目标至少 44px；控件圆角 6px，浮窗圆角 12px。
- 内容页只有一层外边距，默认 16px；列表行内部 8px，表单字段间距 12px；工具栏和底栏与正文对齐。设置内容最大宽度 800px，内部分组采用分隔与标题，取消卡片嵌套卡片。
- 顶部承载身份、返回、分享和局部工具。插入、添加选中、创建、保存等主要确认动作放底部，取消在其前面；底部操作不随长列表滚走。每个可见任务只保留一个主要动作。
- 搜索、来源、范围、结果、已选内容遵循稳定顺序；空态给出下一步，加载尽量保留已存在的有效内容；键盘、右键与触控路径保持可用。

## 请求行为与验收

首次访问立即加载。已有数据在短时间往返切换时直接复用；相同资源的进行中请求合并；切换引发的重复读取受约 5 秒共享冷却保护。关键词保持短防抖，手动刷新及写入成功触发的数据更新及时执行。隐藏页面不持续请求；缓存和共享状态保持有界。实现以实际请求链审查结果为准，避免引入无必要的通用调度器。

应使用假时钟和真实请求计数验证快速往返、进行中切换、隐藏/显示、多消费者与变更后的更新；不得仅以 CSS 文本检查证明交互正确。

4. 同步指南设计规范及变更记录，打包部署到 3080，校验安装产物和真实页面；本次操作不修改或重启 3384。
5. 保留现有无关改动，不修改 DSH 源码，不擅自更改共享分支或发布。

## 实施记录

已实施统一主题与尺度令牌，作用域覆盖设置、原生设置弹窗、公共浮窗及线索 Tab；宿主按钮／输入的圆角与焦点角色一并映射。设置由嵌套卡片改为连续行与语义标题，复用宿主 Switch，关闭态保留视觉开关；正文最大 800，导航根据自身容器切换。

包插入与重命名确认位于固定底栏；包内容和添加页的导航／查询／列表归同一滚动区域，滚动加载监听真实容器。范围与收集分别将内容和底栏分区；选包 radio 不写入，底部添加／创建才提交，取消保留选择和草稿。详情有实际修改才显示保存；分享主操作由预览推进到导出，可选检查位于预览中，反馈在内容区，忙碌时取消替换重置。确认弹窗同样采用统一留白、内容滚动和独立底栏。

请求实现复用原有有界缓存：业务完成结果 15s、运行状态 5s；最后消费者离开后的进行中读取保留 5s，返回清除保护定时器，超时才中止。普通状态观察不清业务缓存，来源展示注册只失效目录。实际动作及安装终态失效；Retry／Recheck 强刷；普通配置关闭允许复用，避免开关窗口重复请求。

独立审查后修正了短窗底栏裁剪、浅色按钮 hover 对比不足、蓝色小字对比、资源选择框及设置弹窗开关触控命中不足。资源 label 的视觉 checkbox 保留 14px，触控命中 44×44，标题／插入／右键保持独立。移除废弃样式与描述上的无用危险态；未引入新依赖、调度框架或第二状态库。

### 请求证据

业务读仍为有界 15s／80 条，状态读 5s，最后消费者离开后的网络保护为一次性 5s，而不是每个动作等待 5s。正文、编辑基线、任务进度与写操作不缓存。

- 假时钟覆盖：4.9s 回切复用，5.1s 无消费者中止；消费者相互独立；再次离开重置保护；完成／失效／返回清理定时器；强刷旧响应不能污染新缓存。
- 真实 HTTP：请求人为延迟 5.2s；页面离开 **4540ms** 后返回，列表网络请求共 **1 次**。来源设置连续重开两次，新增 inspect／connection 状态请求 **0 次**。原始数据见[请求计数](assets/unified-product-design-2026-10-22/clues-request-metrics.json)。
- 真实 wrapper：无变更配置连续开关三次，两种状态各只请求一次；修改 CLI 路径后关闭配置，两种状态都重新读取并恢复就绪。
