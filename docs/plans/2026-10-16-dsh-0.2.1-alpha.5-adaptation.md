# DSH 0.2.1-alpha.5 适配记录（v0.28.0-alpha.0）

> 状态：本地适配验证完成，未发布。以下结果由主线程执行并确认；未修改 DSH 源码或升级真实用户 profile。

## 1. 已批准范围

- 宿主精确目标：DSH `0.2.1-alpha.5`；插件版本：`0.28.0-alpha.0`。
- 单支持线：13 条 DSH peer 下限为 `^0.2.1-alpha.5`，开发依赖与 CI / 安装脚本钉精确宿主版本；不写旧版运行时兼容层。
- DSH `0.2.0-rc.2` 用户继续使用 npm 已发布的插件 `0.26.1`；`0.27.0` 尚未发布到 npm。`0.2.0-rc.1` 用 `0.24.1`，`0.1.7` 线用 `0.22.1`。
- alpha 发布后使用 `dsh plugin --profile web add dsh-better-sidebar@0.28.0-alpha.0`；`latest` 不是本 alpha 的安装目标。
- 不修改 DSH 源码，不升级真实用户 profile，不发布 npm。

## 2. 两项删除型迁移

### Connection admission

alpha.5 删除 `webRuntime`。插件注入改为 `connection`；所有 `/sidebar` HTTP/WS 路由调用 `ctx.connection.requestRejection(req)`，仅返回 `undefined` 才继续。Host/Origin 与浏览器认证由宿主裁决，不复制 trusted-host 列表或恢复插件自建例外；拒绝应发生在读取请求体或升级之前。

### Runtime invariants

[官方升级指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.5/docs/upgrade-guide/v0.2.0-rc.2/remove-runtime-invariants/guide.md) 明确移除 `@deepseek-ai/dsh-invariants`、`ctx.invariants` 与各宿主包的 `/invariant` 子路径，无替代包。不能把不存在的版本钉成 alpha.5，也不保留 rc.2 包混入新支持线。

本插件同步移除 invariant companion、类型、包导出与打包清单。压缩种子回归移除上游 `/invariant` 导入，继续以公开 surface fold、seed validator 和事件结构断言覆盖原行为，不自建 invariant 框架。

## 3. 当前执行目录、labels 与兼容性判定

用户已选择文件 / Git / 终端与新建 sidechat 跟随会话 `working_directory`。live 读 `ctx.workingDirectory.get(session)`；cold 通过 `ctx.sessionQuery.observeSession` 的 `projectionMode: 'all'` 读取当前目录，lease 在 `finally` 释放。linked worktree 仍按 base 目录记账；sidechat seed 尾部 stamp 当前 cwd，避免历史 seed 目录覆盖新线程当前目录。

alpha.5 的 `TerminalBlockLabels` 新增必填 `commandLine(line)`，两个消费者已补，全 21 份词典 key 同步。伴随更新 Cordis `4.0.5`、schemastery `~3.18.5-alpha.2`、group `1.0.5-alpha.2`、include `1.0.10`。稳定 Cordis 同时满足 alpha 宿主与稳定传递 loader 的范围，无需 override；剩余 4 条 peer 警告仅来自可选 better-locale 的旧 DSH 支持线。

[官方兼容性升级指南](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-alpha.5/docs/upgrade-guide/v0.2.1-alpha.3/plugin-engines-dsh/guide.md) 描述 alpha.3 之后的规则变化：package 自有 `engines.dsh` 存在时独立决定兼容性，否则才读 DSH peers；拒绝记录由 `peers` 更名 `requirements`。本插件不新增 `package.json#engines.dsh`，仍用 13 peers；第三方 `dsh.plugin.json#engines.dsh` 不参与宿主判定。
