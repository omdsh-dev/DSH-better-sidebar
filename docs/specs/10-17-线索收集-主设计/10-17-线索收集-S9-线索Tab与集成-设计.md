## 1. 目标与边界

将来源基础、依赖安装、内置来源、上下文引用、浮窗、分享及设置组合成可实际使用的「线索收集」Tab，完成公共 API 文档、入口装配和真实宿主验收。

主页面融合为上小下大的两个区域，线索包在上、查找资料在下，同时可见，不再切换任务视图。2026-10-19 用户明确要求恢复上下分栏并大胆设计现代、人类友好的样式；此前“不使用高亮条”的约束继续有效。不把集合强行变成任务树，不另造自绘右侧栏。

视觉基线为 [已确认的紧凑蓝色预览](assets/clues-ui-reference.html)。它是静态参考，不是已实现功能。2026-10-22 用户批准的最新修订优先：原生 @ 标题候选、底部右侧“插入资料／加入线索包”、每浏览器首次帮助模态、稳定刷新与本机只读 API。详见[实施记录](../../plans/2026-10-22-clues-reference-flow.md)。截图中示例计数与页码不是实际数据契约。

## 2. 主页面上下两区

### 上方：紧凑线索包架

- 显示当前工作区的包，提供显式切换／选择其他工作区包的入口；选择仅改变浏览范围，不复制原包或限制读取权限。
- 通用箭头横栏支持展开／折叠，标题、计数及独立工具常驻；其下是按需搜索与内部滚动目录。包接口一次传输全量，本地每批 12 条渐进显示，无页码／翻页箭头。集合 glyph 与包名对齐，名称最多两行，成员数为次级信息，独立引用 SVG 始终可见。上限仍为容器高度的 38% 与 260px 中较小值；资源区折叠时包目录可填满剩余空间。新建包名称与确认移入独立任务浮窗，主栏不再展开创建表单。
- 包名称单击打开包管理；独立、明确的 @ 按钮调用 S5 插入包引用到草稿，不发送。两个动作是并列按钮与焦点，不嵌套或靠事件冒泡区分。
- 标题始终用于查看或管理，@ 始终用于引用，与单条资料的动作语义一致；鼠标、键盘和触控均可访问。
- 新建、导入及更多动作位于包区工具栏。主界面不显示工作区绑定标记。
- 包的排序可按最近使用；最近使用只改变列表顺序，不生成访问权限或过期记录。

### 下方：主要的查找与浏览区

- 来源／类型在搜索之前以图标和完整名称常驻展示，点击直接切换，按内容自然宽度换行而非等宽大块，不使用来源下拉。当前范围并入浏览标题工具栏，导航下方是紧凑搜索命令栏。刷新从当前查询起点重载连续列表，清除搜索是独立操作。列表使用完整宽度，结果内部滚动；尾部接近视口时按 nextCursor 自动追加并去重，不渲染页码或翻页按钮。续页时保留已读行／选中，失败在底部显式重试且停止自动请求，无下一游标就结束；数量限制提示在结果末端。搜索、来源、范围入口及紧凑选择动作条不跟随长结果移出可视区，小窗口保留整区滚动兜底。
- 当前来源显示置顶区和浏览／搜索结果，二者都可控制展开或高度，置顶很多时不能无限挤占结果区。
- 支持 list 的来源无查询也可在明确范围中逐页浏览；不支持则显示置顶与搜索／直接添加入口，不伪造“无数据”。
- 搜索关键词、资源 URL／路径共享一个输入框。明确可解析的 URL／路径进入候选解析，显示识别结果后由用户插入、置顶或加入包；不自动创建远程资源。
- 查询不支持、需要选择仓库／目录、未授权、无结果、来源关闭及网络错误是不同状态，均提供下一步入口。
- 浏览标题工具栏提供范围选择／编辑入口，范围表单在明确点击后进入任务浮窗；缺范围只提示行动入口，不自动弹窗。GitHub 可输入 owner/repo 或仓库 URL，Open／Closed／All 直接单选；飞书文件夹／知识库等范围类型同样直接展示单选项。本期不为选择范围扫描整个账号。按 workspaceId 与 sourceId 在插件非秘密配置中保存最近一次显式选择；无记录时提示选择，不能猜 cwd。换范围重置 cursor 并取消旧请求，完整资源 URL 的直接添加仍可独立使用。
- 来源切换只拉当前所需数据；默认全开不代表后台遍历全部来源。保存各来源最近浏览位置可以使用 UI 状态，但稳定引用由 S1 持有。
- 置顶只影响常用显示。结果与置顶重复项明确去重或显示已置顶状态，不误算分页数量；来源不提供 total 时只用 nextCursor 判断续页，不伪造总数或页码。
- 单条线索标题打开详情，独立引用按钮插入资料，置顶动作常驻可见；不要求先悬停才能发现动作。键盘焦点与粗指针目标仍遵循宿主规范。
- 资源复选框常驻，不再进入独立多选模式。跨批／来源选择保留，底部只显示数量及动作；点击收集进入已有集合浮窗，内部复核列表可逐项取消。引用与加入包是不同动作；加入包在窗内以可搜索的单选列表显示目标包名称与成员数，先选目标再显式确认；筛选不丢失已选目标，确认区保持显示目标名称。无包时可直接以所选资源创建包。批量操作部分失败时移走成功项、保留未完成项，写入完成刷新上方包列表。

## 3. 包管理与添加成员

包管理使用 S6 集合窗口，管理名称和现有成员；显示成员来源图标、标题及必要状态。包是集合，移除成员不删除原资源或已插入的稳定引用。

“添加成员”进入同一个浮窗内的独立页面，复用多来源浏览器的能力、图标、游标滚动续页、置顶及搜索／直接添加输入。跨来源多选在页面内保留；确认加入后去重返回包管理，取消不改变包成员。

选择范围只包含用户明确选中的条目，不因全选当前页而扩展到远端全部结果。切换来源或追加批次不能丢掉已选成员，也不能默默勾选尚未加载的资源。

包编辑草稿、滚动和搜索状态在子页返回后保留。包保存、成员原始内容保存是不同动作：编辑某个成员不会自动丢弃尚未保存的包名称或选择。冲突及关闭保护遵循 S1/S6。

## 4. 详情、绑定与上下文动作

单条详情由来源提供预览／编辑内容并由 S6 承载。先使用缓存 read 展示查看页，只有点击编辑才取得新的 loadEdit 保存基线；只读或权限不足明确显示原因及原始来源入口。插入与保存分开，不把“保存文档”当作“发送给 Agent”。

绑定配置只在包或单条线索的内部管理页面。允许显式选择关联工作区；控制旁显示：

> 在此工作区的新会话中自动提供引用，读取时获取最新内容。

并说明解绑不删除线索或旧会话引用。绑定、置顶和 @ 展示是三种独立关系，界面不要用同一个开关代替。主页面不额外显示绑定徽章。

新操作只插入稳定引用；历史“包含内容”模式的兼容行为由 S5 定义，不再生成重复菜单行，不新增类型级“强制正文”策略。详情底栏右侧依次“加入线索包”“插入资料”；有编辑草稿时 Save 是唯一主动作。收集窗口由窗口服务持有，从聊天 chip、包成员或隐藏 Tab 的详情均可打开，取消不写、部分失败保留未完成项。包内来源关闭或缺失时保留成员状态，不悄悄删除成员。

## 5. 每浏览器首次 Tab 内简图（2026-10-23，替代模态）

帮助位于线索 Tab 内页头下方，只有三步图标：“选资料 → 插入 → 发送”，每步一句短文，另补一句多条资料可加入线索包。无全屏、遮罩、portal、focus trap、aria-modal 或 inert，不阻塞聊天及其他资料操作。窄 Tab 仍容纳三个短步骤，不展开为冗长使用手册。

首次可见显示，用户关闭后保存浏览器级版本标记；打开不等于已读。页头 `?` 随时展开／收起；只有焦点位于帮助内时 Escape 关闭，不劫持全局按键。关闭恢复到页头触发按钮。存储失败仍可使用，不自动进行授权或读取正文。

## 6. 风格、响应与稳态

- **2026-10-23 当前优先**：公共 `ClueResourceInfo` 保留同响应已得的状态／作者／负责人／时间、Issue／PR 编号及 PR head→base、计数和文件路径／大小。主列表、置顶、包成员和添加候选使用同一行内摘要，详情使用完整摘要；未提供的字段不伪造，不为每行增加外部读取。任务 all／active(false)／completed(true)、GitHub open／closed／all 均由来源声明 filters 驱动，仓库未确定前不开放可能破坏范围的筛选。
- **2026-10-23 详情统一**：所有来源共用刷新／来源工具栏、摘要、查看／编辑、正文、稳定底栏。只有脏草稿显示一个底栏 Save；内嵌飞书 renderer 不重复保存，Markdown 与安全 XML 投影可读。已读正文、列表分页／滚动保留；显式刷新仅固定按钮忙碌。保存后的已知资料展示快照只采用来源确认结果更新，快照写盘失败不把已提交的远端保存伪装成可重试失败。
- **2026-10-23 缓存替代旧 TTL 条款**：成功读在激活期保留（128项／约16 MiB LRU），错误不缓存；重新进入／折叠／切源／重开只补取失效或未完成的数据，不因15秒到期重读。手动刷新、写入和真实账号／能力变化失效，身份变更保守清除业务读；普通状态检查不清。sessionId 保留隔离；保存跨 clueId／locator 及 session 失效；历史内容发送强制 fresh read，Agent 读不经过浏览器缓存。最后消费者离开后在飞最多保留5秒，新关键词取消旧搜索，无新周期轮询。

- 靠近 DSH 的字体、控件、图标、紧凑间距、表面和边框，不用独立的营销视觉语言。
- **2026-10-20 横栏与任务窗修订（当前优先）**：采用共享 `WorkbenchSection` 的右／下箭头横栏，折叠保活且停止自动读取；包和资源纵向滚动加载，不再点击分页。范围、新建、收集确认充分利用已有浮窗；选中资源和目标草稿关闭重开仍保留，任务窗打开期间固定 owner 工作区，会话／工作区切换在关闭后应用。引用入口统一宿主上下文注入 SVG，替代裸文本 @，不改变草稿语义。真实关闭原生 Tab 会销毁局部草稿，不声明跨销毁恢复。其他 Tab 本轮不迁移，但可复用横栏与滚动 hook。
- **2026-10-20 原生多彩修订（优先于此前全中性图标／来源反馈）**：用户指出图标和 UI 太素，要求参考 DSH 原生插件多彩设计。保留中性面板和紧凑密度，在内容上使用有填充、折角、层叠或负空间的彩色 glyph：集合为蓝／暖双色；本地来源／资源复用宿主文件夹与文件类型图标；飞书文档蓝／绿、任务琥珀；GitHub issue 绿、PR 蓝／绿。颜色只表示来源身份，不伪装实际资源状态。来源选中允许轻业务蓝 tint，收集／创建主路径用业务蓝，置顶用琥珀；资源选择仍中性。所有自绘色层只消费 alias，不能把默认墨色 brand-primary 当成蓝；无高亮条、无大面板染色、不改交互与网络机制。新旧记录分开归档。
- **2026-10-20 编辑器化修订**：参考 Codex Desktop／VS Code／Zed 的安静工作台，页头／包目录为中性 chrome，资源为基础表面；统一 12px 边距和轻量标题，桌面资源行以 36px 为基准，粗指针目标至少 44px。来源工具带按内容宽度自然换行，包分页并入标题，范围摘要并入浏览工具栏，结果分页固定在列表之外。置顶列表最多 96px 内滚；收集返回／标题／数量合并一行，加载／错误／空态属于目标列表内部，长目标名有界显示且保留完整 title，确认区不被其挤走。
- **2026-10-19 融合布局修订（优先于第四轮双视图）**：保留单一工作台，上方三条紧凑包列表、下方主要浏览，包搜索按需展开。包标题与元信息建立轻量层级，下方以主搜索输入组织查找，直接勾选后通过底部清单引用或明确确认入包。移除模式切换和大段引导。选中使用中性宿主交互填充与字重，不使用高亮条、下划线或点阵；正文 13px、区标题沿用宿主 12／14px 字体与主题表面，主操作前景／填充／hover 成对消费宿主令牌。
- 2026-10-22 刷新修订：同一查询后台刷新保留已读行、选择、草稿与滚动，只有固定刷新按钮显示忙碌状态；错误在结果区显式重试，依赖 checking／目录加载不在搜索上方插行。历史业务读缓存为15s／80项（已被2026-10-23激活期缓存取代）、5s在飞回切保护，写入按库／置顶／包／内容读族失效，无新轮询。已关闭收集窗草稿缓存最多 30 项，活跃或写入中草稿只由窗口组件持有。
- 两区同时保留挂载；包的筛选／滚动不影响资料查询、范围草稿或多选。隐藏原生 Tab 时停止自动读取并取消在飞浏览，重新可见只补取已失效或未完成的数据，热缓存不发请求。来源初次解析只加载一次；用户点击来源时恢复该来源自己的未提交输入、已提交查询和范围草稿，最多保留 20 个来源；范围在其他入口改变时丢弃旧游标与过时范围草稿，不将别的来源关键词或 cursor 发往新来源。来源被关闭后的自动回退仍重置为列表。包最近使用记录更新不重置范围草稿，加入包选项在聚焦时刷新。
- 复用原生 Tab 注册与可见性；keepMounted 下隐藏即停止轮询／主动查询，事件驱动失效不丢失，重新可见按需补刷。
- 来源、依赖、连接和每资源请求按插件单例或共享在飞结果管理，不随 Tab body 数量成倍执行。缓存有界，正在使用及在飞键不被随意淘汰；持久引用不受缓存淘汰影响。
- 取消过时搜索、切换范围／关闭浮窗时释放对应请求；不通过循环探测 cwd 或认证状态保持“活跃”。
- 内容滚动与分页位置明确，窄屏不缩小字体硬塞两栏；图标用明确尺寸并有名称。

## 7. 入口与文档集成

本 Spec 拥有最终公共导出、宿主／客户端入口接线、内置来源注册、Tab 注册、共享词典和外部接入指南的集中装配。子 Spec 提供可独立测试模块与说明，不在并行阶段竞争同一入口文件。

原生 Tab 沿用现有注册／注销账本与服务等待机制，不以槽出现代替服务就绪；来源故障不会让已有文件树、任务页或终端承载消失。不能擅自接管宿主保留的文件预览类型。

更新公共接入指南，覆盖 host/client 服务边界、来源／类型／图标、能力声明、CLI 安装／连接、HTTP/MCP 示例、富文本编辑器扩展、窗口服务、稳定引用与分享能力；内置来源使用同一公共 API。提供最小外部来源测试样例，不要求消费者 value-import 内部组件。

新增文案沿用仓库本地化流程，尤其同步日语词典；MarkdownText 使用统一 props。新增 chunk 必须按仓库规定同步镜像，否则复用现有懒加载机制。

## 8. 整体验收

### 用户流程

1. 首次打开显示每浏览器一次的帮助模态，关闭后显示小包区与主要查找区，`?` 可随时再看，关闭后焦点返回触发按钮；标题与 @ 独立可聚焦，键盘可直接进入结果滚动区，上方包操作与下方查询互不打断。
2. 内置来源默认开启，缺 CLI／授权仅显示状态；不后台安装、登录或读取全部资源。
3. 用户在设置中确认 CLI 安装计划，可看到目标、阶段、取消和真实结果；手动路径可用，安装与授权分开，两个来源共享同一依赖状态。
4. 明确授权后分页浏览 GitHub／飞书支持的范围，搜索与直接链接输入可用；不支持 list 的来源也能添加和插入。
5. 置顶、取消置顶、组包、包内添加页跨来源选择、返回和草稿保存均符合前述语义；多包、多来源、多置顶不会使页面不可用。
6. 包与单条的 @ 只插入草稿，输入框直接 @ 等价；发送默认不拉正文，模型用同机 curl／本地只读 API 按需获取最新内容。
7. 新工作区会话自动提供绑定引用，主会话、子代理、恢复会话均能读取有效旧引用；关闭入口、解绑、长期闲置和重启不形成新的读取禁令。
8. 浮窗加载、编辑、保存、冲突、授权失效、最大化／还原、窄屏及包／成员／添加页返回保持状态；复杂未编辑结构不被破坏。
9. 两种 .cluepack 模式导入导出正确；接收方缺来源／授权可见未解析状态，快照可离线读且不冒称最新；导入不执行安装或原始写入。
10. 设置页两个入口同读同写；来源及 @ 全开／全关、包 @ 开关和深链接行为正确；已有 Tab／viewer 设置无回归。

### 工程验证

- 按各子 Spec 运行独立契约、组件和负面测试，再运行仓库 build、typecheck、test、check:consumer-types、check:engines，以及 pack 后 test:mount 的真实宿主冒烟；具体命令以届时 package scripts 和仓库规则为准。
- 目标基线是 DSH 0.2.1-rc.1。本次设计侦察发现本机依赖树仍有 0.2.0-rc.2；旧类型面、部分远程产物对照不能当成目标版本运行证据。执行前先对齐受管开发依赖并核验新增公共服务，再做目标版本 scratch profile 挂载。
- 不修改 DSH 源码；隔离挂载测试是测试环境，不是替换用户当前 GUI。若更新当前 GUI，按实际挂载构建与刷新验证现有地址，不启动另一服务器冒充更新成功。
- Playwright 检查桌面与320/390px窄屏、明暗主题、长名称、多包／多来源／大量置顶、真实图标、编辑器懒加载、无 pageerror、键盘焦点和加载／错误状态。
- keepMounted、多会话、HMR／依赖服务重挂、请求取消、共享缓存和旧功能挂载均需要回归证据。
- 所有自动化来源测试使用隔离 fixture／假 CLI 配置，不继承真实用户 HOME、CLI 登录态或 Keychain；真实第三方账号验证须另行获得用户授权。
- 明确区分“夹具已验证”“实际目标宿主已验证”“真实第三方账号未验证”。没有账号验证不得宣称真实飞书／GitHub全链路成功。

## 9. 设计证据与交接

静态预览已经在桌面、320／390px窄屏和明暗模式检查过布局；这只证明预览，不证明实现、宿主接入、CLI 安装、鉴权或第三方资源操作。

公共契约与可观察结果以各子 Spec 为准。执行前应对新宿主API、内置CLI固定版本与安装分发做目标环境核验；若公开能力不足以满足已批准需求，先报告具体缺口，不暗中修改宿主、加隐式回退或削掉用户编辑需求。

实现完成报告引用新鲜测试结果和未验证项，不沿用设计阶段的截图与调查结论当成功证据。
