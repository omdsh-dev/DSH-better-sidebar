## 1. 目标与边界

将来源基础、依赖安装、内置来源、上下文引用、浮窗、分享及设置组合成可实际使用的「线索收集」Tab，完成公共 API 文档、入口装配和真实宿主验收。

主页面采用两个独立区域，不绘制包与下方全部来源之间的装饰连线，不把纯集合强行变成任务树。不另造自绘右侧栏。

视觉基线为 [已确认的紧凑蓝色预览](assets/clues-ui-reference.html)。它是静态参考，不是已实现功能。以下后续确认优先于预览中尚未呈现的部分：单条 @ 按钮、Tab 内全覆盖帮助、同窗独立添加页、绑定说明小字。截图中示例计数与页码不是实际数据契约。

## 2. 主页面两区

### 上方：统一线索包库

- 显示当前工作区的包，提供显式切换／选择其他工作区包的入口；选择仅改变浏览范围，不复制原包或限制读取权限。
- 紧凑节点矩阵有独立搜索和分页，页面高度受控。大量包不能无限堆叠挤走下方来源区。
- 包节点主体单击调用 S5 插入包引用到草稿，不发送；底部窄条显示成员数并打开包管理浮窗。两个动作是独立按钮及焦点，不嵌套按钮或靠事件冒泡区分。
- 首屏使用清晰的插入符号与底条编辑图标，hover／focus 解释动作。不会因为“打开包详情”的旧行为误发引用。
- 新建、导入及更多动作位于包区工具栏。主界面不显示工作区绑定标记。
- 包的排序可按最近使用；最近使用只改变列表顺序，不生成访问权限或过期记录。

### 下方：多来源浏览器

- 来源入口使用图标和名称。窄栏横向可滚动来源导航，宽幅可使用侧导航；来源增加时不把每个入口压成不可读的宽度。
- 当前来源显示置顶区和浏览／搜索结果，二者都可控制展开或高度，置顶很多时不能无限挤占结果区。
- 支持 list 的来源无查询也可在明确范围中逐页浏览；不支持则显示置顶与搜索／直接添加入口，不伪造“无数据”。
- 搜索关键词、资源 URL／路径共享一个输入框。明确可解析的 URL／路径进入候选解析，显示识别结果后由用户插入、置顶或加入包；不自动创建远程资源。
- 查询不支持、需要选择仓库／目录、未授权、无结果、来源关闭及网络错误是不同状态，均提供下一步入口。
- 来源输入框附近提供范围选择／编辑入口。GitHub 可输入 owner/repo 或仓库 URL；飞书按来源能力选择文件夹／知识库／任务范围。本期不为选择范围扫描整个账号。按 workspaceId 与 sourceId 在插件非秘密配置中保存最近一次显式选择；无记录时提示选择，不能猜 cwd。换范围重置 cursor 并取消旧请求，完整资源 URL 的直接添加仍可独立使用。
- 来源切换只拉当前所需数据；默认全开不代表后台遍历全部来源。保存各来源最近浏览位置可以使用 UI 状态，但稳定引用由 S1 持有。
- 置顶只影响常用显示。结果与置顶重复项明确去重或显示已置顶状态，不误算分页数量；来源不提供 total 时使用上一页／下一页，不伪造 01/总页数。
- 单条线索标题打开详情，有独立 @ 按钮插入草稿，另有置顶和查看／编辑动作；hover 才出现的辅助动作也必须在 focus-visible 或触摸模式可达。
- 列表可进入多选模式，批量插入或加入包，不让每行常驻按钮挤掉标题。

## 3. 包管理与添加成员

包管理使用 S6 集合窗口，管理名称和现有成员；显示成员来源图标、标题及必要状态。包是集合，移除成员不删除原资源或已插入的稳定引用。

“添加成员”进入同一个浮窗内的独立页面，复用多来源浏览器的能力、图标、分页、置顶及搜索／直接添加输入。跨来源多选在页面内保留；确认加入后去重返回包管理，取消不改变包成员。

选择范围只包含用户明确选中的条目，不因全选当前页而扩展到远端全部结果。切换来源或翻页不能丢掉已选成员，也不能默默勾选尚未加载的资源。

包编辑草稿、滚动和搜索状态在子页返回后保留。包保存、成员原始内容保存是不同动作：编辑某个成员不会自动丢弃尚未保存的包名称或选择。冲突及关闭保护遵循 S1/S6。

## 4. 详情、绑定与上下文动作

单条详情由来源提供预览／编辑内容并由 S6 承载。可编辑类型直接编辑；只读或权限不足明确显示原因及原始来源入口。插入与保存分开，不把“保存文档”当作“发送给 Agent”。

绑定配置只在包或单条线索的内部管理页面。允许显式选择关联工作区；控制旁显示：

> 在此工作区的新会话中自动提供引用，读取时获取最新内容。

并说明解绑不删除线索或旧会话引用。绑定、置顶和 @ 展示是三种独立关系，界面不要用同一个开关代替。主页面不额外显示绑定徽章。

默认插入引用，显式“包含内容”的行为由 S5 定义；不新增类型级“强制正文”策略。包内来源关闭或缺失时保留成员状态，不悄悄删除成员。

## 5. 帮助覆盖层

页头有 `?` 按钮。用户首次进入该 Tab 时自动显示一次，之后通过 `?` 主动打开；关闭状态按浏览器本地偏好记录，不因切换会话而再次强制出现，不依赖远端账号。

帮助覆盖整个 Tab 内容区域，保留关闭／返回操作，不遮挡聊天、其他 Tab 或整个应用。采用简洁关系图加短说明：来源提供资源；线索是一个资源引用；线索包是多个线索集合。图中的边只表达这些真实关系。

解释主体点击与 @ 插入、底条管理、置顶不复制内容、工作区绑定自动提供引用，以及默认按需读取。键盘焦点在帮助内合理管理，关闭后回到触发点；减少动态效果时无强制动画。

## 6. 风格、响应与稳态

- 靠近 DSH 的字体、控件、图标、紧凑间距、表面和边框，不用独立的营销视觉语言。
- #3388BB 为该功能的设计主色，通过统一组件边界的语义令牌配置；组件不散落字面色，不能覆盖宿主全局主题。深浅主题的文字和焦点对比度单独验收。
- 复用原生 Tab 注册与可见性；keepMounted 下隐藏即停止轮询／主动查询，事件驱动失效不丢失，重新可见按需补刷。
- 来源、依赖、连接和每资源请求按插件单例或共享在飞结果管理，不随 Tab body 数量成倍执行。缓存有界，正在使用及在飞键不被随意淘汰；持久引用不受缓存淘汰影响。
- 取消过时搜索、切换范围／关闭浮窗时释放对应请求；不通过循环探测 cwd 或认证状态保持“活跃”。
- 内容滚动与分页位置明确，窄屏不缩小字体硬塞两栏；图标用明确尺寸并有名称。

## 7. 入口与文档集成

本 Spec 拥有最终公共导出、宿主／客户端入口接线、内置来源注册、Tab 注册、共享词典和外部接入指南的集中装配。子 Spec 提供可独立测试模块与说明，不在并行阶段竞争同一入口文件。

原生 Tab 沿用现有注册／注销账本与服务等待机制，不以槽出现代替服务就绪；来源故障不会让已有文件树、任务页或终端承载消失。不能擅自接管宿主保留的文件预览类型。

更新公共接入指南，覆盖 host/client 服务边界、来源／类型／图标、能力声明、CLI 安装／连接、HTTP/MCP 示例、富文本编辑器扩展、窗口服务、稳定引用与分享能力；内置来源使用同一公共 API。提供最小外部来源测试样例，不要求消费者 value-import 内部组件。

新增文案沿用仓库本地化流程，尤其同步日语词典；MarkdownText 使用统一 props。新增 chunk 必须按仓库规定同步镜像，否则复用现有懒加载机制。

## 8. 整体验收

### 用户流程

1. 首次打开 Tab 显示帮助，关闭后可正常使用；后续会话不强制重开，`?` 可随时查看。
2. 内置来源默认开启，缺 CLI／授权仅显示状态；不后台安装、登录或读取全部资源。
3. 用户在设置中确认 CLI 安装计划，可看到目标、阶段、取消和真实结果；手动路径可用，安装与授权分开，两个来源共享同一依赖状态。
4. 明确授权后分页浏览 GitHub／飞书支持的范围，搜索与直接链接输入可用；不支持 list 的来源也能添加和插入。
5. 置顶、取消置顶、组包、包内添加页跨来源选择、返回和草稿保存均符合前述语义；多包、多来源、多置顶不会使页面不可用。
6. 包主体与单条 @ 只插入草稿，输入框直接 @ 等价；发送默认不拉正文，模型用统一只读工具按需获取最新内容。
7. 新工作区会话自动提供绑定引用，主会话、子代理、恢复会话均能读取有效旧引用；关闭入口、解绑、长期闲置和重启不形成新的读取禁令。
8. 浮窗加载、编辑、保存、冲突、授权失效、最大化／还原、窄屏及包／成员／添加页返回保持状态；复杂未编辑结构不被破坏。
9. 两种 .cluepack 模式导入导出正确；接收方缺来源／授权可见未解析状态，快照可离线读且不冒称最新；导入不执行安装或原始写入。
10. 设置页两个入口同读同写；来源及 @ 全开／全关、包 @ 开关和深链接行为正确；已有 Tab／viewer 设置无回归。

### 工程验证

- 按各子 Spec 运行独立契约、组件和负面测试，再运行仓库 build、typecheck、test、check:consumer-types、check:engines，以及 pack 后 test:mount 的真实宿主冒烟；具体命令以届时 package scripts 和仓库规则为准。
- 目标基线是 DSH 0.2.1-rc.1。本次设计侦察发现本机依赖树仍有 0.2.0-rc.2；旧类型面、部分远程产物对照不能当成目标版本运行证据。执行前先对齐受管开发依赖并核验新增公共服务，再做目标版本 scratch profile 挂载。
- 不修改 DSH 源码；隔离挂载测试是测试环境，不是替换用户当前 GUI。若更新当前 GUI，按实际挂载构建与刷新验证现有地址，不启动另一服务器冒充更新成功。
- Playwright 检查桌面与320/390px窄屏、明暗主题、长名称、多包／多来源／大量置顶、真实图标、编辑器懒加载、无 pageerror、键盘焦点和加载／错误状态。
- keepMounted、多会话、HMR／依赖服务重挂、请求取消、共享缓存和旧功能挂载均需要回归证据。
- 所有自动化来源测试使用隔离 fixture／假 CLI 配置，不继承真实用户 HOME、CLI 登录态或 Keychain；真实第三方账号验证须另行获得用户授权。
- 明确区分“夹具已验证”“实际目标宿主已验证”“真实第三方账号未验证”。没有账号验证不得宣称真实飞书／GitHub全链路成功。

## 9. 设计证据与交接

静态预览已经在桌面、320／390px窄屏和明暗模式检查过布局；这只证明预览，不证明实现、宿主接入、CLI 安装、鉴权或第三方资源操作。

公共契约与可观察结果以各子 Spec 为准。执行前应对新宿主API、内置CLI固定版本与安装分发做目标环境核验；若公开能力不足以满足已批准需求，先报告具体缺口，不暗中修改宿主、加隐式回退或削掉用户编辑需求。

实现完成报告引用新鲜测试结果和未验证项，不沿用设计阶段的截图与调查结论当成功证据。
