图标是来源契约的一部分

来源注册时提供图标与名称；来源切换、详情标题、设置页沿用同一身份。内置使用已有宿主图标与品牌资产，外部来源缺省时采用类型回退。

绑定只在内部设置

绑定工作区放在包或单条线索的编辑浮窗中。主页面保留轻量快捷入口，绑定不作为读取权限。

统一浮窗继续深化

按内容类型设置初始尺寸，提供最大化与还原。从包进入成员后支持返回，保留包内编辑状态；不叠加多层弹窗。
