# 本地修改说明

本插件是在原作 `dsh-better-sidebar` 基础上的个人定制版本。

## 原作

- 原作仓库：[omdsh-dev/DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)

## 本次修改

- 侧边栏默认增加白色背景，并支持在侧边卡片设置中调整白色背景透明度。
- 增加 Markdown 文件之间的链接跳转，点击后在 DSH 侧边栏内打开目标文件，不跳转到系统浏览器。
- 支持 Markdown 文件内部锚点跳转，以及跨文件锚点跳转。
- 为 Markdown 标题生成稳定锚点，并支持 `<a id="..."></a>` 形式的显式锚点。
- 预览时隐藏用于定位的空 HTML 锚点标签，避免在正文中显示原始标签。
- 添加对应的单元测试，覆盖路径解析、跨文件链接、锚点链接和预览处理。

本版本仅用于个人使用和定制开发，原作版权与许可证保持不变。
